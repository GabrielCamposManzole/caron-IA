# Caronas UTFPR

Plataforma Web desenvolvida para facilitar a mobilidade acadêmica na UTFPR Campus Guarapuava. O sistema conecta Alunos, Professores e Visitantes em um ecossistema seguro e transparente de compartilhamento de viagens, reduzindo o tempo de espera no deslocamento diário e organizando o fluxo de vagas.

## Stack Tecnológica

* **Frontend:** Angular 20+
* **Styling / UI:** Tailwind CSS
* **Dados & Backend:** `json-server` (Mock para MVP / E2) -> Supabase (Entrega E3)
* **Gerenciamento de Código:** Gitflow (`main` / `develop`) com proteção de branches e SDD por Portões (UTF-SDD)
