# Caronas UTFPR

Plataforma web para organizar caronas universitárias na UTFPR Campus Guarapuava, conectando motoristas e passageiros para reduzir o tempo de espera e os custos de deslocamento diário.

- **Frontend:** Angular 20+, conforme a stack definida para o projeto.

- **Dados na Entrega 2:** json-server.
- **BaaS na Entrega 3:** pendente de confirmação pela equipe.
